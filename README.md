# MVAC — Military Vehicle AI Classifier

A fully offline, deep learning–powered desktop application that identifies **89 distinct military vehicle classes** — fighter jets, bombers, helicopters, main battle tanks, naval vessels, and more — from a single uploaded image.

Built with **EfficientNetV2-M**, exported to **ONNX**, and served through a polished **Tkinter** desktop UI. No internet connection is required at inference time.

## ✨ Features

- **89-class fine-grained classification** spanning fixed-wing aircraft, helicopters, main battle tanks, and naval vessels
- **Fully offline inference** — no API calls, no cloud dependency, works air-gapped
- **Top-5 prediction breakdown** with live confidence bars
- **Vehicle knowledge base** — country of origin, operational role, top speed, and armament for every class
- **Multiple image input methods** — file dialog, drag-and-drop, `Ctrl+O`, and clipboard paste (`Ctrl+V`)
- **Real-time event log** for full inference transparency
- **Demo mode** — the app still runs and demonstrates the UI even without a trained model present
- Clean, dark-themed, resizable desktop interface

## 🏗️ Architecture

```
Image Input → Preprocess (resize 224×224, normalize)
            → EfficientNetV2-M (ONNX Runtime, CPU)
            → Softmax → Top-5 Classes
            → Vehicle Knowledge Base Lookup
            → GUI Display (Tkinter)
```

| Component        | Details                                              |
|-------------------|-------------------------------------------------------|
| Backbone          | `tf_efficientnetv2_m` (via `timm`), ImageNet-pretrained |
| Input size        | 224 × 224 × 3                                         |
| Loss function     | Focal Loss with per-class alpha + label smoothing     |
| Regularization    | MixUp, Mosaic augmentation, stochastic depth          |
| LR schedule       | Linear warmup + Cosine Annealing Warm Restarts        |
| Class imbalance   | Weighted random sampling (inverse class frequency)    |
| Export format     | ONNX (opset 14, dynamic batch axis)                   |
| Inference runtime | ONNX Runtime (CPU Execution Provider)                 |

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/shauryavardhan.24/DRISHTI-MV.git
cd DRISHTI-MV
```

### 2. Install dependencies

```bash
pip install onnxruntime pillow numpy
```

> Optional: install `tkinterdnd2` to enable drag-and-drop image loading.
```bash
pip install tkinterdnd2
```

### 3. Add the model files

Place the following two files (produced by `train.py`) in the project root:
- `military_classifier.onnx`
- `metadata.json`

If these files are missing, the app automatically starts in **Demo Mode** with randomized predictions so you can still explore the UI.

### 4. Run the app

```bash
python app.py
```

## 🧠 Training Your Own Model

The full training pipeline (`train.py`) is designed to run on **Lightning AI Studio** or **Google Colab** with GPU acceleration.

```bash
python train.py
```

Key training features:
- Downloads and merges multiple public Kaggle datasets automatically
- Applies tiered augmentation (ultra/heavy/light) based on per-class image count
- Trains an EfficientNetV2-M backbone with differential learning rates for backbone vs. head
- Exports the best checkpoint to ONNX and validates it with `onnx.checker`
- Generates accuracy, loss, and learning-rate curves for reporting

> **Note:** You will need your own Kaggle API credentials (`KAGGLE_USERNAME` / `KAGGLE_KEY`) to download the source datasets. Set these as environment variables or in `~/.kaggle/kaggle.json` — never commit credentials to the repository.

### Datasets used
- `crsuthikshnkumar/fighter-aircraft-data-set`
- `crsuthikshnkumar/military-helicopter-data-set`
- `a2015003713/militaryaircraftdetectiondataset`
- `antoreepjana/military-tanks-dataset-images`
- `oleksandershevchenko/ship-classification-dataset`
- Several supplementary Kaggle datasets (skipped gracefully if unavailable)

## 📊 Results

- **Validation accuracy:** ~82% across dozens of fine-grained vehicle classes
- **Inference latency:** sub-second on standard CPU-only laptop hardware
- Random-chance baseline for this many classes is roughly 1%, underscoring the difficulty of fine-grained military vehicle disambiguation (e.g. T-72 vs T-80 vs T-90, or F-15 vs F-18)

## ⚠️ Limitations & Disclaimer

- This is a research/educational **image classification** project trained entirely on **publicly available datasets**. It has no access to classified, proprietary, or restricted data.
- The classifier identifies vehicle *type* only — it performs no targeting, tracking, geolocation, or weapons-related function of any kind.
- It only supports **single static images** (not real-time video) and classifies the single dominant vehicle in frame.
- Accuracy varies by class depending on available training data; rare vehicle types with few public images are more prone to misclassification.
- Not intended for operational or safety-critical use.
